# Technische und organisatorische Maßnahmen (TOMs)

| Bereich | Maßnahme |
|---|---|
| Zutritt und Zugang | Hosting in EU-Rechenzentren mit Zutrittskontrolle der Anbieter; Zugang zu Systemen nur mit Passwort (Argon2id) und Sitzungs-Cookies (httpOnly, sicher), Rollen pro Workspace, Mandantentrennung über Row Level Security. |
| Zugriff | Rollenmatrix (owner, admin, editor, reviewer, client), Mandanten sehen nur ihre Marke, jede Änderung im Audit-Log. |
| Weitergabe | Verschlüsselte Übertragung (TLS), Objektspeicher mit serverseitiger Verschlüsselung, keine Weitergabe an Dritte außer gelisteten Subprozessoren, Residency-Guard blockiert Aufrufe außerhalb der EU technisch. |
| Eingabe | Audit-Log für Uploads, Rechtebestätigungen, Korrekturen, Freigaben, Exporte, Löschungen. |
| Auftrag | Verarbeitung nur über Funktionen der Software; keine Nutzung von Kundendaten zum Training ohne Opt-in. |
| Verfügbarkeit | Tägliche Backups der Datenbank, Objektspeicher mit Versionierung, Wiederanlauf über Temporal-Workflows. |
| Trennung | Getrennte Buckets für Rohmaterial und Ableitungen, Workspace-Isolation auf Datenbankebene, Löschfristen pro Workspace. |
| Löschung | Lösch-Workflow mit Nachweis (gelöschte Objektschlüssel, gelöschte Zeilen), Lifecycle-Regeln im Objektspeicher, Backup-Löschung binnen 30 Tagen. |
| Provenienz | Optionale C2PA-Signatur der Exporte, Kennzeichnung synthetischer Elemente. |
| Organisation | Benannte Verantwortliche für Datenschutz, Prozess für Datenpannen (48 Stunden), jährliche Überprüfung der TOMs. |
